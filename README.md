# Конструктор медиакита турагента

Первая локальная версия сайта, в которой турагент заполняет анкету и получает готовый медиакит из четырёх страниц по переданному PPTX-шаблону. Хостинг и домен на этом этапе не настроены: версия предназначена для демонстрации и проверки.

## Локальный запуск

Понадобится актуальная LTS-версия Node.js.

```bash
npm install
npm run dev
```

После запуска откройте адрес, который появится в терминале. Обычно это `http://localhost:5173`.

Чтобы проверить итоговую сборку:

```bash
npm run build
npm run preview
```

## Что входит в первую версию

- пошаговая анкета для телефона, планшета и компьютера;
- загрузка портретного фото;
- четыре обязательных показателя опыта;
- направления, типы туристов, преимущества для партнёров и решаемые запросы;
- два кейса с запросом, действиями и результатом;
- необязательное изображение-доказательство в каждом кейсе;
- контакты: телефон, Telegram, Instagram и VK в одной строке через `/`, сайт;
- кликабельные ники соцсетей и выбор одной заполненной ссылки для QR-кода;
- предпросмотр четырёх страниц и скачивание PDF;
- готовый пример данных для быстрой проверки макета.

Регистрация, оплата, личный кабинет, серверное хранение анкет и интеграции с CRM в первую версию не входят. После закрытия страницы введённые данные не сохраняются.

## Ограничения контента

Лимиты рассчитаны для фиксированного PPTX-макета. Они не позволяют тексту вытеснять элементы, менять утверждённый размер шрифта или становиться слишком мелким. Форма показывает ошибку, если превышено допустимое количество символов или пунктов.

| Поле | Ограничение |
| --- | ---: |
| Специализация | 42 символа |
| Имя и фамилия | 34 символа |
| Текст «О себе» | 330 символов |
| Позиционирование | 150 символов |
| Направления | до 4 пунктов, по 28 символов |
| Типы туристов | до 5 пунктов, по 45 символов |
| Польза партнёру | до 3 пунктов, по 64 символа |
| Решаемые запросы | до 7 пунктов, по 72 символа |
| Каждая часть кейса | 135 символов |
| Ник соцсети | 32 символа |
| Финальная фраза | 105 символов |

Имя, специализация, портрет, описание, позиционирование, минимум один пункт каждого списка, четыре показателя и все три текстовые части каждого из двух кейсов обязательны. Контакты необязательны. Если указан ник Telegram, Instagram или VK, рядом требуется полная ссылка с `http://` или `https://`; именно она делает ник кликабельным. При наличии хотя бы одной корректной ссылки нужно выбрать одну из заполненных ссылок для QR-кода.

Фотографии-доказательства в кейсах необязательны. Интерфейс должен заранее показывать требования к допустимому размеру и пропорциям загружаемых изображений; сами визуальные размеры блоков исходного шаблона не меняются.
